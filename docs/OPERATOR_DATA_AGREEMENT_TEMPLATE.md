## 1. Purpose & Scope

This lean agreement establishes the operational terms under which an urban waste collection operator (**"Operator"**) voluntarily shares vehicle telemetry data with **KOLEKTA** (**"Platform"**), an independent open-source civic technology initiative.

The sole purpose of this data sharing is to inform residents of Luanda about active waste collection movements, reducing uncollected street waste and improving civic transparency.

## 2. Data Exchanged

### 2.1 Authorized Telemetry Data
The Operator agrees to provide automated position reports from its collection fleet via the Platform's secure ingestion API (`POST /api/v1/gps/positions`), containing solely:
- **Vehicle Identifier:** An alphanumeric internal fleet code (e.g., `VEH-042`).
- **Geographic Coordinates:** Latitude and longitude (WGS84).
- **Timestamp:** Time of GPS fix (`recorded_at`).
- **Telemetry Indicators (Optional):** Instantaneous speed (km/h) and heading (degrees).

### 2.2 Prohibited Personal Data
To safeguard worker privacy and comply with privacy-by-design standards:
- **No Driver Information:** Operator shall **not** transmit driver names, phone numbers, personnel records, or biometric data.
- **License Plates:** License plate numbers are restricted from citizen-facing public interfaces and are treated as confidential operational metadata.

## 3. Platform Commitments

KOLEKTA commits to the following terms:
1. **Public Good Use Only:** Telemetry data is processed exclusively to display live vehicle positions on a public map and compute historical passage patterns for citizens.
2. **Zero Commercial Monetization:** Telemetry data will **never** be sold, licensed, or shared with commercial advertising brokers.
3. **Open-Source Transparency:** The code processing operator telemetry is publicly auditable under the GNU AGPL-3.0.
4. **Security & Encryption:** Telemetry is transmitted exclusively over encrypted HTTPS/TLS channels using per-operator API keys.

## 4. Operator Rights & Ownership

1. **Non-Exclusive:** This agreement does not restrict the Operator from sharing telemetry with other municipal or internal platforms.
2. **Revocability:** The Operator may pause or terminate data transmission at any time without penalty by revoking its API credentials.
3. **No Warranty / Estimates Disclaimer:** The Operator is not liable to citizens for route predictions generated by KOLEKTA. Predictions are explicitly presented as statistical estimates, not binding schedules.
